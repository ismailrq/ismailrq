# CV language versions

The portfolio's CV dropdown reads these files when the site is built:

- English: `Ismail-Raqi-CV.pdf` (the existing CV).
- French: `Ismail-Raqi-CV-fr.pdf`.

Add or replace the PDFs in this folder, then rebuild and deploy the site. A language with no PDF shows “Coming soon” instead of a download link. The existing HTML CV remains at `/cv/index.html`.
